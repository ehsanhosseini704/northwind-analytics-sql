# northwind-analytics-sql

Business-driven SQL queries and analytics using the Northwind sample database.

## Overview
This repository contains a collection of SQL queries designed to solve
real-world business and analytics questions using the Northwind sample database.
The focus is on practical scenarios such as customer segmentation, sales analysis,
order patterns, and performance evaluation.

## Topics Covered
- High-value customer identification
- Order and delivery analysis (late orders, trends)
- Customer grouping and segmentation
- Sales performance by employee
- Data quality and edge-case handling
- Advanced SQL techniques (joins, aggregations, subqueries, window functions)

## Database
- Northwind sample database

## Purpose
This project is intended to demonstrate practical SQL skills for data analysis
and business reporting scenarios.
